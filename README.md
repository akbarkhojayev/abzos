# abzOS

A custom Linux distribution — "Developer & Cybersecurity Edition" — built in two parallel
editions, each producing a bootable live ISO.

## Editions

### 1. Ubuntu (Casper) Edition — `abzOS-1.0-amd64.iso`
- Base: Ubuntu Noble, built via chroot in `chroot/`
- Desktop: XFCE4 + LightDM, Yaru-dark theme, WhiteSur icons, Kali-style shell prompt
- Bundled pentesting tools: nmap, sqlmap, nikto, gobuster, ffuf, john, hydra,
  aircrack-ng, radare2, wireshark, binwalk, etc., each with a GUI launcher
  (`.desktop` entry) under Network/Security categories
- Built with `scripts/setup_chroot.sh` (installs/configures inside the chroot) and
  `scripts/build_iso.sh` (squashfs + `grub-mkrescue` → hybrid BIOS/UEFI ISO)

### 2. Debian (Bookworm) "Hyprland-style" Edition — `abzOS-Debian-1.0-amd64.iso`
- Base: Debian 12 Bookworm, built via Docker (`scripts/Dockerfile.debian.final`)
- Desktop: Sway (Wayland) + Waybar + Wofi + Mako, configured with Hyprland-style
  neon-cyan gaps/borders and a cyberpunk theme
- Built with `scripts/build_debian_iso.sh`, which extracts the kernel/initrd and
  streams the container filesystem into a squashfs (`scripts/stream_squashfs.py`)
  before assembling the ISO with `grub-mkrescue`

Both editions share branding assets in `scripts/assets/` and log in as user
`abzos` / password `abzos` (root password `toor`, passwordless sudo for the
live session).

## Layout

- `chroot/`, `image/` — Ubuntu edition working tree (chroot root + casper ISO staging)
- `debian_chroot/`, `debian_image/` — Debian edition working tree (Docker container
  export + live ISO staging)
- `scripts/` — Dockerfiles, build scripts, branding assets, and QEMU-based test/debug
  tooling (boot verification, serial console inspection, screenshot capture)
- `debug_archive/` — historical boot/desktop troubleshooting screenshots and logs
  (gitignored; kept locally for reference)

`chroot/`, `debian_chroot/`, `image/`, `debian_image/`, the `*.iso` files, and
`debug_archive/` are all regenerated by the build scripts and are gitignored.

## Building

Ubuntu edition:
```
sudo scripts/setup_chroot.sh   # run inside the chroot, or via scripts/run_in_chroot.sh
scripts/build_iso.sh
```

Debian edition:
```
docker build -f scripts/Dockerfile.debian.final -t abzos-debian:final .
scripts/build_debian_iso.sh
```

## Status

Both ISOs build and boot to a working desktop (verified via QEMU); most of the
`debug_archive/` history is from tracking down an X11/LightDM boot race on the
Debian/Sway edition.
