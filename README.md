# abzOS

A custom Linux distribution — Debian 12 (Bookworm) with a Sway (Wayland) desktop,
bundled developer and cybersecurity tooling, and a cyberpunk-styled UI. Builds to a
single bootable live ISO: `abzOS-1.0-amd64.iso`.

## What's inside

- **Base**: Debian 12 Bookworm, built as a Docker image (`scripts/Dockerfile`) and
  exported straight into a squashfs live filesystem — no chroot on the host.
- **Desktop**: Sway + Waybar (top bar) + Wofi (launcher) + Mako (notifications),
  autologin via LightDM straight into a tiled, neon-cyan themed session.
- **Tools**: build-essential/gcc/gdb, git, python3, and a cybersecurity toolkit
  (nmap, sqlmap, nikto-adjacent web/network tools, john, hydra, aircrack-ng,
  binwalk, wireshark/tshark, etc.), each with a `.desktop` launcher under
  Network/Security categories in the app launcher.
- Login: user `abzos` / password `abzos` (root password `toor`, passwordless sudo
  for the live session).

## Layout

- `scripts/Dockerfile` — the single source of truth for the OS image: packages,
  users, LightDM/Sway/Waybar/Wofi/Mako config, branding, bundled tool launchers.
- `scripts/build_iso.sh` — builds the Docker image, extracts the kernel/initrd,
  streams the container filesystem into a squashfs (`scripts/stream_squashfs.py`),
  and assembles a hybrid BIOS/UEFI ISO with `grub-mkrescue`.
- `scripts/verify_iso_boot.py` — boots the built ISO in headless QEMU, drives the
  serial console to confirm lightdm/Xorg/sway/waybar actually came up, and saves a
  framebuffer screenshot (`iso_verify.png`) plus the serial transcript
  (`verify_output.txt`).
- `scripts/test_iso.sh` — launches the ISO in an interactive QEMU window.
- `scripts/generate_wallpapers.py` — regenerates the procedural wallpaper/logo in
  `scripts/assets/` used by the Dockerfile's branding step.
- `image/` — build staging directory (kernel, initrd, squashfs, grub.cfg);
  regenerated by `build_iso.sh` and gitignored.
- `abzOS-1.0-amd64.iso` / `.sha256` — build output, gitignored.

## Building

```
scripts/build_iso.sh
```

This builds the `abzos:1.0` Docker image, then produces `abzOS-1.0-amd64.iso` in
the repo root.

## Testing

```
python3 scripts/verify_iso_boot.py   # automated: boots in QEMU, checks lightdm/sway/waybar via serial, screenshots the framebuffer
scripts/test_iso.sh                  # interactive: opens the ISO in a QEMU window
```

## Status

Verified end-to-end via a real ISO boot in QEMU (not just the container): GRUB →
kernel → live-boot → `graphical.target` → LightDM → Xorg → Sway, with Waybar and
the wallpaper rendering correctly (confirmed via serial diagnostics and a
framebuffer screendump, not just the container-internal render).
