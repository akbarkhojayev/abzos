# abzOS

A lightweight, modern, and reliable custom Linux distribution — Debian 12 (Bookworm) with a stock GNOME desktop, full hardware and virtualization driver suite, and bundled developer and cybersecurity tooling. Builds to a single bootable live ISO: `abzOS-1.0-amd64.iso`.

## What's inside

- **Base**: Debian 12 Bookworm, built as a Docker image (`scripts/Dockerfile`) and exported straight into a squashfs live filesystem — no chroot on the host.
- **Desktop**: Stock GNOME Shell (`gnome-core`: Nautilus, GNOME Console, Settings, Text Editor, and the rest of GNOME's own apps), autologin via GDM straight into a clean, dark-styled session with the abzOS wallpaper. No custom panel, theme, or shell extensions — just GNOME's native top bar, Quick Settings, and notifications.
- **Drivers & Hardware Support**:
  - Full wireless & network firmware (`firmware-iwlwifi`, `firmware-realtek`, `firmware-atheros`, `firmware-brcm80211`, `firmware-sof-signed`, etc.)
  - GPU & Video acceleration (`xserver-xorg-video-all`, Intel, AMD, ATI, Nouveau, QXL, VMware, Mesa DRI, Vulkan, VA-API)
  - Virtual machine guest integration (`spice-vdagent` dynamic screen resizing and clipboard sharing, `qemu-guest-agent`, `open-vm-tools-desktop`)
  - Audio & Bluetooth (`pipewire`, `pipewire-pulse`, `wireplumber`, `pavucontrol`, `bluez` — GNOME Shell's own Quick Settings handle the network/Bluetooth/volume indicators natively, no separate tray applets)
  - Filesystems (`dosfstools`, `ntfs-3g`, `exfatprogs`, `e2fsprogs`, `parted`)
- **Display & Resolution**: Automatic display detection and dynamic auto-resizing via `spice-vdagent` and `xrandr`, filling QEMU/virtual machines and physical monitors without black letterboxes.
- **Tools**: build-essential/gcc/gdb, git, python3, and a cybersecurity toolkit (nmap, sqlmap, john, hydra, aircrack-ng, binwalk, wireshark/tshark, etc.), each with a `.desktop` launcher under Network/Security/Development categories.
- **Login**: user `abzos` / password `abzos` (root password `toor`, passwordless sudo for the live session).

## Layout

- `scripts/Dockerfile` — the single source of truth for the OS image: packages, drivers, users, GDM/GNOME config (via dconf), branding, bundled tool launchers.
- `scripts/build_iso.sh` — builds the Docker image, extracts the kernel/initrd, streams the container filesystem into a squashfs (`scripts/stream_squashfs.py`), and assembles a hybrid BIOS/UEFI ISO with `grub-mkrescue`.
- `scripts/verify_iso_boot.py` — boots the built ISO in headless QEMU with KVM, checks GDM/Xorg/GNOME Shell via serial, and saves a framebuffer screenshot (`iso_verify.png`) plus the serial transcript (`verify_output.txt`).
- `scripts/test_iso.sh` — launches the ISO in an interactive QEMU window with VirtIO graphics and SPICE vdagent dynamic window resizing.
- `scripts/generate_wallpapers.py` — regenerates the procedural wallpaper/logo in `scripts/` used by the Dockerfile's branding step.
- `image/` — build staging directory (kernel, initrd, squashfs, grub.cfg); regenerated by `build_iso.sh` and gitignored.
- `abzOS-1.0-amd64.iso` / `.sha256` — build output, gitignored.

## Building

```bash
scripts/build_iso.sh
```

This builds the `abzos:1.0` Docker image, then produces `abzOS-1.0-amd64.iso` in the repo root.

## Testing

```bash
python3 scripts/verify_iso_boot.py   # automated: boots in QEMU, checks gdm/gnome-shell via serial, screenshots the framebuffer
scripts/test_iso.sh                  # interactive: opens the ISO in a QEMU window with dynamic display resizing
```

## Status

Verified end-to-end via a real ISO boot in QEMU: GRUB (full-screen, 1920x1080) → kernel → live-boot → `graphical.target` → GDM → Xorg → GNOME Shell, with the top bar, dash, wallpaper, Nautilus, GNOME Console, and Settings all rendering correctly.
